# Internationalization (i18n)

The app uses `i18next` + `react-i18next` with a browser language detector and a curated set of locales.

## Configuration
- `src/i18n/index.ts` wires i18n with resources for `en, es, ar, pt, de, fr`.
- `LanguageProvider` synchronizes the document’s `lang` and `dir` attributes and provides language metadata (flags, RTL, labels).

## Usage
- `useTranslation()` to access `t()` and helpers.
- Language switch via `LanguageProvider` methods or dedicated UI in the kiosk start form.

## Content examples
- Loading screen pulls animated phrases from `loading.phrases` in each locale, enabling delightful microcopy without code changes.

## Rationale
- Treat language as data; minimize conditionals in views.
- Centralize RTL handling at the document level to avoid per-component hacks.
