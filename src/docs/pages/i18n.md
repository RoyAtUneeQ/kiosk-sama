## Internationalization (i18n)

The app uses `i18next` + `react-i18next` with a browser language detector, a curated set of locales, and a thin `LanguageProvider` for ergonomics.

### Configuration
- `src/i18n/index.ts` wires i18n with resources for `en, es, ar, pt, de, fr` and enables `LanguageDetector`.
- `LanguageProvider` keeps `<html lang>` and `<html dir>` in sync, exposes flags/labels/RTL metadata, and stores preferences in `localStorage`.

### Usage
- Use `useTranslation()` to access `t()` and helpers.
- Switch language via `LanguageProvider` helpers or the kiosk start form.

### Content
- The loading screen cycles phrases from `loading.phrases` per locale to deliver delightful microcopy without code changes.

### Rationale
- Treat language as data to minimize conditionals in views.
- Centralize RTL at the document level to avoid per‑component workarounds.
